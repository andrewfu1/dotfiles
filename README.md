# Dotfiles

Pure-style Starship prompt with Catppuccin Mocha colors for macOS and Ubuntu.

```text
~/code/training  main  12m 8s
❯
```

## Install

Run on your Mac and separately on your Ubuntu server:

```sh
git clone https://github.com/andrewfu1/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

Open a new shell. On macOS, select **Dotfiles — Mocha** in iTerm2's Profiles menu.

## Update

Run on each machine:

```sh
cd ~/dotfiles
git pull --ff-only
./install.sh
```
